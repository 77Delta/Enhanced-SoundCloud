<h1 align="center">Enhanced SoundCloud</h1>

## An extension for SoundCloud that adds the following features:

- Spotify-like **lyrics**.
- Track's **music video** as website's background.
- A **playback speed changer** with **Preserve pitch** option.
- A **Download track** button on all tracks that redirects you to the [Cobalt](https://cobalt.meowing.de/) website.
- A **Debloat** option that deletes all useless elements on screen and unblurs blurred elements.
- An option to change the website's **accent color** to the track cover's color.
- **Discord RPC** support (**requires additional set up**).

# Installation:

- For Chrome-based browsers, install the extension from [Chrome Web Store](https://chromewebstore.google.com/detail/enhanced-soundcloud/oheiflpjconebcfilhpbbiimjflknnjj)
- For Firefox-based browsers, install the extension from [Firefox Addons](https://addons.mozilla.org/es-ES/firefox/addon/enhanced-soundcloud/)

# How to set up Discord RPC:

## What you need:

- Discord desktop running.
- **Node.js** installed.

## Installation:

1. Download and unzip or clone this repository.
2. Open the **rpc** folder.
3. - **Windows:** execute `install.bat`.
   - **macOS or Linux:** open a terminal in the folder and run: `bash install.sh`.
4. Play a track on SoundCloud it will show on your Discord activity.

## Uninstallation:

1. Open the **rpc** folder.
2. - **Windows:** execute `uninstall.bat`.
   - **macOS or Linux:** open a terminal in the folder and run: `bash uninstall.sh`.
